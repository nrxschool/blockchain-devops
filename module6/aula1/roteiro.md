# Aula 6.1: Introdução ao Desenvolvimento de Smartcontracts EVM

## Introdução

Nesta aula, vamos explorar os fundamentos do desenvolvimento de smartcontracts na Ethereum Virtual Machine (EVM). Vamos discutir a história e a arquitetura do mundo EVM e aprender a configurar os ambientes de desenvolvimento com as ferramentas Foundry e ScaffoldETH2.

## Tooling de Ferramentas EVM

- Truffle / Ganache
- Etherjs / Web3js
- Hardhat / Brownie / ApeWorkx
- Foundry / Viem / Slither
