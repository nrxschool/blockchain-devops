# Curso de Blockchain DevOps Revisado

## Módulo 1: Fundamentos do Blockchain e Hyperledger Besu

**Aula 1.1: Introdução ao Blockchain**

| Explicar sobre a evolução das blockchain e as principais diferenças entre suas arquiteturas

- Arquiteturas de Blockchain.
- Bitcoin, Ethereum EVM, Polygon, Solana, Polkadot, Near, Hyperledger, R3Corda.
- Hyperledger Besu

**Aula 1.2: Instalação e Configuração Inicial do Besu**

| Utilização local do Hyperledger Besu

- Instalaçãodo Hyperledger Besu.
- Configurações iniciais e exploração da interface de linha de comando.

## Módulo 2: Desenvolvimento e Implantação de Smart Contracts


**Aula 2.1: Smart Contracts no Ethereum**

| Mostrar como é o ciclo de vida de dev, build, teste, deploy de um smartcontract ERC20

- Escrita, teste e deploy de smart contracts usando Solidity.

**Aula 2.2: JSON-RPC**

| Interagir com o Besu local via JSON-RPC

- Interação dos métodos básicos
- Interação com smart contracts via Besu RPC.

**Aula 2.3: Integração e Automação de CI/CD**

| Montar um CI/CD para testar e deployar um smart-contract

- Introdução a CI/CD.
- Configuração de pipelines de CI/CD para automação de testes e deployment de smart contracts.

## Módulo 3: Arquitetura e Operações de Node Blockchain

**Aula 3.1: Configurando Docker e Dockerfiles para Besu**

| Preparar o Besu para rodar em containers

- Criação de um ambiente isolado usando Docker.
- Escrevendo Dockerfiles para customização do node Besu.

**Aula 3.2: Kubernetes e Orquestração de Containers**

| Aprendendo a rodar containers

- Configuração de Kubernetes para gerenciar clusters de nodes Besu.
- Uso de Helm para gerenciamento de pacotes no Kubernetes.

## Módulo 4: Monitoramento, Observabilidade e Segurança

**Aula 4.1: Configurando Prometheus e Grafana**
- Implementação de Prometheus para coleta de métricas.
- Configuração de Grafana para visualização e monitoramento.

**Aula 4.2: Segurança e Best Practices**
- Práticas recomendadas de segurança para operações blockchain.
- Estratégias de segurança em CI/CD e ambientes de blockchain.

## Módulo 5: Escalabilidade e Performance

**Aula 5.1: Técnicas de Escalabilidade para Blockchain**
- Estratégias para escalonar um node Besu em produção.
- Balanceamento de carga e gestão de tráfego de rede.

**Aula 5.2: Otimização e Tuning de Performance**
- Técnicas de tuning para maximizar a performance do node Besu.
- Análise de gargalos e otimização de recursos.

## Mentalidade DevOps Integrada ao Curso
- Breve discussão sobre cultura DevOps relacionada ao tema da aula.
- Exemplos de falhas e aprendizados no contexto de blockchain.
